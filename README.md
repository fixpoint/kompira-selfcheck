# kompira-selfcheck

Kompira Enterprise を使っている環境を、お客様ご自身で確かめるためのスクリプトです。

## 入手

スクリプトは、Release からダウンロードしてください。Release には、スクリプトとハッシュ値のファイル (`SHA256SUMS`) を添付しています。ハッシュ値を確かめてから使ってください。

## 版とリリース

- 版はスクリプトごとに `X.Y.Z` の形で付け、次のように上げます
  - X: 互換性のない変更 (終了コード、`--json` の出力の項目、オプションの意味を変えるもの)
  - Y: 確かめる項目やオプションを増やすもの
  - Z: 誤った判定の修正や、表示・案内の改善
- Release もスクリプトごとに作ります。タグは `<ディレクトリ>-v<版>` の形 (例: `ca-check-v1.0.0`) です
- 変更の履歴は、各ディレクトリの `CHANGELOG.md` をご覧ください
